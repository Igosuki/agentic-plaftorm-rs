# Dead-Letter Queues
A message that fails delivery `dlq.max_attempts` times (default 5) is moved to the dead-letter queue named `<topic>.dlq`. Redelivery backoff starts at 1000 ms and doubles each attempt up to `dlq.max_backoff_ms` (default 60000).
Dead-letter messages keep their original headers plus `x-nimbus-failure-reason` and `x-nimbus-attempts`. DLQ retention defaults to 336 hours (14 days).
Replay a dead-letter queue with `nimbusctl dlq replay orders.dlq --to orders`.
