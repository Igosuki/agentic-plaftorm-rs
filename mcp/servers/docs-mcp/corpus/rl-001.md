# Rate Limits
Nimbus Queue applies per-principal rate limits. The default publish limit is 1000 messages per second and 50 MiB per second per principal; the default fetch limit is 200 requests per second.
Requests over the limit receive error code 429 `RATE_LIMITED` with a `retry-after-ms` header. Set `limits.publish_per_sec` and `limits.fetch_per_sec` in `nimbus.toml` to change them; 0 disables the limit.
The admin API is limited to 20 requests per second per token and this is not configurable.
