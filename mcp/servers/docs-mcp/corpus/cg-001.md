# Consumer Groups
A consumer group shares a topic's partitions among its members; each partition is assigned to exactly one member at a time. Offsets are committed per group and partition.
The default `consumer.session_timeout_ms` is 10000 and the heartbeat interval is 3000 ms. A member missing heartbeats beyond the session timeout triggers a rebalance.
The default `consumer.max_poll_records` is 500. A group cannot usefully have more active members than partitions; extra members stay idle.
Reset offsets with `nimbusctl group reset-offsets <group> --to-earliest`.
