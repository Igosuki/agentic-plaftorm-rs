# Configuration Reference
Nimbus Queue is configured through `nimbus.toml`. Key `retention.hours` sets message retention and defaults to 168 hours (7 days); set `retention.bytes` to cap per-partition size (default 10 GiB).
Key `topic.default_partitions` defaults to 3 and the maximum is 1024 partitions per topic. Key `broker.max_message_bytes` defaults to 1048576.
Key `broker.data_dir` defaults to `/var/lib/nimbus`. Key `broker.fsync_interval_ms` defaults to 200; set it to 0 to fsync on every write.
Changing `retention.hours` takes effect on reload via `nimbusctl reload` without restarting the broker.
