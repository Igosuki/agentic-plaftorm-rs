# Getting Started with Nimbus Queue
Nimbus Queue is a durable message queue. Install the broker with `nimbus-broker --config nimbus.toml`; it listens on port 7420 for clients and port 7421 for the admin API.
Create a topic with `nimbusctl topic create orders --partitions 6`. The default replication factor is 3 and the default partition count is 3.
Publish with `nimbusctl publish orders "hello"`. Messages are limited to 1 MiB (1048576 bytes) by default.
